## 에셋별 생성 규칙

### A. 단독형 광고 (4, 5, 6번)

```
One Message, One Image
├── 단 하나의 핵심 메시지만 강렬하게 전달
├── Focal Point: 시선을 사로잡는 명확한 중심 피사체
└── 여백 확보: 텍스트(카피) 공간(Negative Space)을 의도적으로 비워둠
```

- 메시지와 비주얼이 1:1 대응 — 복잡한 구성 금지
- 카피 영역은 API 생성 시 비워두고, 후처리에서 문구 합성
- 로고(좌상단) + CTA(우하단) 배치

### B. 스토리형 광고 (7번 — 3장 세트)

```
기승전결 (Narrative Flow)
├── Image 1 (Hook): 문제 상황 제기 / 강렬한 호기심 유발
│   "이 캐릭터 이름, 알아? 🤔"
├── Image 2 (Action): 앱을 통한 해결 과정 / 즐거운 경험
│   "음절 조합으로 맞춰봐! 🎮"
└── Image 3 (Result): 해결된 상태 / 만족감 / CTA
    "티니핑 박사 등극! 🏆" + 로고 + CTA
```

- 시각적 일관성: 동일한 배경 톤, 캐릭터 스타일 유지
- 로고/CTA: **마지막 장(3번)에만** 배치
- 3장을 하나의 프롬프트 세션에서 순차 생성 (톤 일관성)

### C. 스토어 스크린샷 (8번 — 4~5장)

```
실제 앱 화면 기반
├── 실제 앱 실행 → 화면 캡처
├── 폰 프레임 합성 (선택)
├── 상단 캡션 + 하단 서브텍스트 합성
└── 파노라마 효과: 배경이 이어지는 듯한 스크롤 유도
```

- **AI 생성이 아닌 실제 앱 스크린샷 사용**
- Image 1: 가장 강력한 핵심 가치 (Hook)
- Image 2~4: 주요 기능 가이드 및 사용 모습
- 파노라마: 공통 배경 그라데이션 + 연속 장식 요소

## 공통 작업 원칙 (Nano Banana Optimized)

### 해상도/퀄리티

1. **정확한 비율로 생성** — API 호출 시 목표 aspect ratio 명시
2. **묘사 디테일을 높여 해상도(화질) 확보** — 프롬프트에 재질감, 조명, 디테일 묘사 추가
3. **리사이즈 시 LANCZOS 보간** — 품질 손실 최소화

### 브랜드 반영

1. 모든 이미지는 주조색(`#FF4B8B`)과 무드(Cute & Playful)를 따름
2. 보조색(`#7EC8E3`), 액센트(`#B47AEA`)로 포인트
3. 배경은 `#FFF0F5` 또는 핫핑크→스카이 그라데이션
