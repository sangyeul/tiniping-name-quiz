## 1. 제품 개요

### 1.1 앱 정보

| 항목 | 내용 |
|------|------|
| **앱 이름** | 티니핑 이름맞추기 |
| **부제** | 하츄핑부터 사뿐핑까지! 캐릭터 퀴즈 |
| **패키지명** | `com.seomihye.tiniping_name_quiz` |
| **플랫폼** | Android + iOS (Flutter 단일 코드) |
| **카테고리** | 퍼즐 (1차) / 교육 (2차) |

### 1.2 제품 비전

캐치! 티니핑 6시즌 140마리 캐릭터를 **블러/모자이크/실루엣** 이미지로 보고, 글자를 조합하여 이름을 완성하는 퀴즈 앱. 4지선다보다 능동적인 **음절 조합 방식**으로 학습 효과와 재미를 극대화.

### 1.3 핵심 가치 제안

- **능동적 참여**: 4지선다가 아닌 음절 조합으로 직접 이름 완성
- **3단계 도전**: 블러 → 모자이크 → 실루엣, 같은 캐릭터도 3번 즐길 수 있음
- **2가지 모드**: 이름 맞추기 + 이미지 맞추기 역퀴즈
- **전시즌 수록**: 1기 감정~6기 프린세스까지 140마리 완전판

### 1.4 태그라인

**"이 티니핑 이름, 맞출 수 있어?"**

## 2. 브랜드 전략

### 2.1 핵심 브랜드 가치

| 가치 | 설명 |
|------|------|
| **재미(Fun)** | 글자 조합 + 타이머로 게임처럼 즐기는 캐릭터 학습 |
| **함께(Together)** | 부모와 아이가 "이거 누구지?" 하며 즐기는 가족 놀이 |
| **도전(Challenge)** | 블러→모자이크→실루엣 3단계, 140마리 전부 맞추면 티니핑 박사! |

### 2.2 브랜드 페르소나

> **"티니핑을 전부 아는 동네 언니/오빠"**

아이들 눈높이에서 "이건 하츄핑이야! 하트가 있잖아~" 하고 알려주는 사람.
어렵지 않고, 틀려도 "아깝다! 다시 해볼까?" 하는 다정한 톤.

### 2.3 톤앤매너

| 축 | 방향 | 예시 |
|----|------|------|
| **격식** | 반말 (초등학생 친구 톤) | "정답! 역시 티니핑 박사!" |
| **무게** | 가벼움 90% + 격려 10% | "아깝다! 정답은 바로핑이야" |
| **실패** | 좌절감 최소화 | "시간 초과! 좀 더 빨리빨리~" |

**금기 사항:**
- 캐릭터 비하/부정적 묘사 금지
- "틀렸어!" 대신 "아깝다!" 사용
- 시간 초과 시에도 격려 톤 유지

## 4. 기능 명세

### 4.1 홈 화면

| 항목 | 설명 |
|------|------|
| **시즌 선택** | 전체 / 1기~6기 개별 (복수 선택 가능) |
| **난이도 선택** | 쉬움(⭐) / 보통(⭐⭐) / 어려움(⭐⭐⭐) |
| **문제 수** | 10문제 / 20문제 / 전체 |
| **모드 버튼** | "🎀 이름 맞추기" (핫핑크) / "🔍 이미지 맞추기" (스카이) |

### 4.2 이름 맞추기 퀴즈

| 항목 | 설명 |
|------|------|
| **이미지** | 난이도별 가공: blur / mosaic / silhouette |
| **글자 타일** | 정답 글자 + 방해 글자 (쉬움 2개, 보통 3개, 어려움 5개) |
| **정답 슬롯** | 빈칸 표시 (어려움에서는 글자 수 숨김) |
| **삭제** | 슬롯 터치 삭제 + ⌫ 버튼 |
| **자동 검증** | 슬롯 전부 채우면 자동 판정 |
| **타이머** | 10초 원형 카운트다운 (3초 이하 빨간색) |

### 4.3 이미지 맞추기 역퀴즈

| 항목 | 설명 |
|------|------|
| **출제** | 캐릭터 이름 텍스트 표시 |
| **선택지** | 가공 이미지 4장 (정답 1 + 오답 3, 다른 시즌 우선) |
| **2x2 그리드** | 화면에 맞게 동적 비율 조정 |

### 4.4 힌트 시스템

| 항목 | 설명 |
|------|------|
| **획득** | "광고 보고 힌트 얻기" 버튼 → 보상형 광고 시청 → 3개 지급 |
| **사용** | 문제당 1회, 원본 이미지 상단 1/3 노출 |
| **적용** | 모든 난이도 + 모든 모드 |

### 4.5 피드백

| 상황 | UI | 메시지 |
|------|-----|--------|
| **정답** | 원본 이미지 + 빨간 동그라미 bounce | "정답! 역시 티니핑 박사!" |
| **오답** | shake + 원본 이미지 + 정답 표시 | "아깝다! 정답은 ○○핑이야" |
| **시간 초과** | timer_off + 원본 이미지 | "시간 초과! 좀 더 빨리빨리~" |

### 4.6 결과 화면

| 항목 | 설명 |
|------|------|
| **점수** | N / 총 문제 수 |
| **메시지** | 90%+ "티니핑 박사!" / 70%+ "거의 다 알고 있어!" / 50%+ "열심히 했어!" / 그 외 "다시 도전해봐!" |
| **오답 리뷰** | 가공 이미지 + 정답 이름 목록 |
| **버튼** | 홈으로 / 다시 하기 |

## 5. 이미지 전략 (저작권 대응)

| 구분 | 저장 위치 | 포함 방식 | 저작권 리스크 |
|------|----------|----------|:----------:|
| 퀴즈용 (가공) | 앱 번들 assets/ | blur/mosaic/silhouette (자동 생성) | **낮음** |
| 정답 공개용 (원본) | 외부 URL (Fandom) | `CachedNetworkImage` 런타임 로딩 | **낮음** |
| 앱 아이콘 | 앱 번들 | 블러 처리 이미지 (가공) | **낮음** |

> 앱 바이너리에 원본 이미지 미포함 → 스토어 심사/DMCA 리스크 최소화.
> 상업 배포 시 SAMG Entertainment 사전 허가 권장.
