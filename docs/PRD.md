## 1. 개요

### 1.1 제품 비전

캐치! 티니핑 캐릭터 이미지를 보고 **음절 타일을 조합하여 이름을 완성**하는 퀴즈 앱. 4지선다보다 능동적인 참여로 학습 효과와 재미를 극대화.

- **앱 이름**: 티니핑 이름맞추기 (가칭)
- **플레이스토어 타이틀**: 티니핑 이름맞추기 - 캐릭터 퀴즈

### 1.2 핵심 가치 제안

- 150마리+ 캐릭터를 **음절 조합 방식**으로 재미있게 학습
- **난이도별 이미지 효과** (블러/모자이크/실루엣)로 반복 플레이 유도
- **역퀴즈 모드** (이름→이미지)로 2배의 콘텐츠
- 10초 타이머 + 힌트 시스템으로 긴장감과 보상 동시 제공

### 1.3 플랫폼

- **MVP**: Android + iOS 동시 (Flutter)
- **테스트**: Chrome (web) — 개발 중 검증용

### 1.4 태그라인

**"이 티니핑 이름, 맞출 수 있어?"**

## 3. 기능 명세

### 3.1 Phase 1 — MVP (현재 완료)

#### 홈 화면

| 항목 | 설명 |
|------|------|
| **시즌 선택** | 전체 / 1기~6기 개별 선택 (복수 선택 가능) |
| **난이도 선택** | 쉬움(⭐) / 보통(⭐⭐) / 어려움(⭐⭐⭐) |
| **문제 수** | 10문제 / 20문제 / 전체 |
| **모드 선택** | 이름 맞추기 / 이미지 맞추기 |

#### 이름 맞추기 퀴즈

| 항목 | 설명 |
|------|------|
| **이미지** | 난이도별 가공: blur / mosaic / silhouette |
| **음절 타일** | 정답 음절 + 방해 음절 (난이도별 2~5개) 랜덤 배치 |
| **정답 슬롯** | 빈칸 표시 (어려움에서는 글자 수 숨김) |
| **삭제** | 슬롯 터치 삭제 + ⌫ 버튼 |
| **자동 검증** | 슬롯 전부 채우면 자동 판정 |
| **타이머** | 10초 원형 카운트다운 (3초 이하 빨간색) |

#### 이미지 맞추기 역퀴즈

| 항목 | 설명 |
|------|------|
| **출제** | 캐릭터 이름 텍스트 표시 |
| **선택지** | 가공 이미지 4장 (정답 1 + 오답 3, 다른 시즌 우선) |
| **타이머** | 10초 동일 |

#### 힌트 시스템

| 항목 | 설명 |
|------|------|
| **획득** | "광고 보고 힌트 얻기" 버튼 → 3개 지급 |
| **사용** | 문제당 1회, 원본 이미지 상단 1/3 노출 |
| **적용** | 모든 난이도 + 모든 모드 |

#### 피드백

| 상황 | 동작 |
|------|------|
| **정답** | 원본 이미지 (URL 런타임 로딩) + 빨간 동그라미 bounce + "+1점" |
| **오답** | shake 애니메이션 + 정답 표시 + 원본 이미지 |
| **시간 초과** | timer_off 아이콘 + 정답 표시 + 원본 이미지 |

#### 결과 화면

| 항목 | 설명 |
|------|------|
| **점수** | N / 총 문제 수 |
| **메시지** | 90%+ "티니핑 박사!" / 70%+ "거의 다 알고 있어요!" 등 |
| **오답 리뷰** | 가공 이미지 + 정답 이름 목록 |
| **버튼** | 다시 하기 / 홈으로 |

## 4. 이미지 전략 (저작권 대응)

| 구분 | 저장 위치 | 포함 방식 | 저작권 리스크 |
|------|----------|----------|:----------:|
| 퀴즈용 (가공) | 앱 번들 assets/ | blur/mosaic/silhouette (자동 생성) | **낮음** |
| 정답 공개용 (원본) | 외부 URL (Fandom) | `CachedNetworkImage` 런타임 로딩 | **낮음** |

> 앱 바이너리에 원본 이미지 미포함 → 스토어 심사/DMCA 리스크 최소화.
> 스토어 배포 시 SAMG Entertainment 사전 허가 필수.

## 5. 비기능 요구사항

### 5.1 법적 요구사항

| 항목 | 내용 |
|------|------|
| **캐릭터 저작권** | SAMG Entertainment 사전 허가 필요. 불가 시 AI 생성 이미지 대안 |
| **아동 대상 앱** | COPPA 준수, 개인정보 수집 없음 (100% 로컬) |
| **팬 프로젝트 명시** | 앱 내 "비공식 팬 프로젝트" + 이미지 출처 표기 |

### 5.2 성능 요구사항

| 항목 | 목표 |
|------|------|
| 앱 로딩 | < 3초 |
| 이미지 표시 | < 500ms (로컬 assets) |
| 원본 이미지 로딩 | < 3초 (네트워크) |
| 오프라인 지원 | 퀴즈 자체는 완전 오프라인 (원본 이미지만 온라인 필요) |

## 6. 기술 아키텍처

| 항목 | 선택 | 근거 |
|------|------|------|
| Framework | Flutter 3.41 | 단일 코드로 iOS/Android 동시 |
| Language | Dart 3.11 | Flutter 네이티브 |
| State Management | Riverpod (Notifier) | 간결한 상태관리 |
| Data | 로컬 JSON (assets) | 서버 불필요 |

| 네트워크 감지 | connectivity_plus | 오프라인 알림 |
| 데이터 수집 | Python (requests + Pillow) | Fandom Wiki API |
